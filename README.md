# HR Attrition and Employee Satisfaction Analysis

## 1. Project Overview

This project investigates employee attrition, job satisfaction, salary distribution, employee performance and workforce development.

The aim is to identify patterns and trends within the workforce and generate insights that can support better human resource management and employee retention decisions.

## 2. Project Objectives

- Examine employee attrition across different departments.
- Analyse employee satisfaction across age groups and departments.
- Investigate salary distribution across job positions.
- Evaluate employee performance across departments.
- Explore employee training and development.
- Examine employment types and workforce retention.

## 3. Data Source

The HR dataset was provided as part of the original capstone project instructions.

The original dataset was retained for reference, while a separate cleaned version was prepared for analysis.

## 6. Analysis Performed

The project explored:

- Employee attrition by department.
- Attrition by employment type.
- Employee satisfaction by age group.
- Average salaries by job position.
- Employee performance by department.
- Training hours across departments.
- Employee leave and work-life balance indicators.
